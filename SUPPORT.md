# Support and issue reports

AssayScope is an MIT-licensed research sample supplied without warranty. It is not a
validated scientific product, certified vendor integration or clinical support service.
There is no promised support SLA.

Start with [troubleshooting](docs/troubleshooting.md), the
[documentation index](docs/index.md) and [verification limits](docs/verification.md).
Missing tenant configuration or authorization is an error, not a reason to bypass policy.

For a reproducible bug, include:

- The source revision and exact command or UI steps.
- OS, Node/Python and browser versions; WebGL/GPU details for rendering issues.
- Explicit mode: local simulated, public reference or connected tenant data.
- Expected versus actual behavior and a redacted error.
- Whether the problem reproduces with the supplied synthetic pack.

Do not attach raw/customer data, credentials, tenant state, token-bearing URLs or private
annotations. Screenshots should be reviewed for identifying information. Dataset-rights
questions need the scientific/data owner, not an inferred permission from a public URL.
Report vulnerabilities [privately](SECURITY.md).

For a feature request, describe the lab question or operational requirement, evidence
needed, scientific assumptions and access/cost implications. Adding a platform service
without a concrete requirement is not by itself an improvement.
