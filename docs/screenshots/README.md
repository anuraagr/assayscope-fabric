# Application screenshots

These are real captures from the running local product, not design mockups.
The isolated acceptance runner generates the workbench images, and the documentation
browser check generates the research-report image. Their dates, source/catalog hashes,
browser and hardware are recorded in [verification](../verification.md) and the ignored
acceptance JSON files. They are not labeled cloud UI screenshots.
